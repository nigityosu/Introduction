# プログラミング入門サイト

## 本サイトの目的
 - プログラミング初心者の皆さんにプログラミングの良さを知ってもらう
 - 初心者の段階から簡単にかつ分かりやすく学べるサイト
 - 段階が上がるにつれて実践に入る前にプログラムの構成を作るイメージを育てる
## 本サイトのページイメージ
 - ホームの画面がありそこから大まかに分けられるプログラミングの種類を選択
 - それぞれ初級、中級、上級の三つに分けそれぞれの級から上がるがるのに試験を行い合格することで次の級に行くことになる
 - 各種類から基本的に行う作業をコードを書くのではなく作成するものの構造をパズルのような埋め方で作成させるなおこの作業を初級とする
 - 初級試験は最初のものを助けなしで作成８割正解で合格
 - そこから具体的な言語に移っていきその移り先を中級とする
 - 中級ではパズル式には変わりないがそれぞれのピースが言語の関数や要素になる
 - 中級は指南あり一回、好きなものを決められたピースを正しく使って完成させることで試験が行えるようになる
 - 中級試験は仕様書通りのものを作成するもの一致率が８割を達すると合格
 - 上級はパズル型ではなく雛形や環境またある程度のコード補完がある中で一度自分が作りたいようなものを作る
 - 上級はこれ以上級が上がることはないので卒業試験とする
 - 卒業試験はコード補完を取っ払いこちらで環境構築や雛形の用意などの変わらない作業のみから要望通りのものを作る
 - 卒業試験を合格するとある程度言語の癖や書き方の基本完成形のイメージを作りやすくなってもらってほしい
## 具体的仕様
 - ページ構成
    - ホームページ、説明ページ、お問い合わせページ、各種類の初級＋言語ずつの中級、上級ページ、それぞれの試験ページ
    - 基本はホームページからの移動
    - ハンバーガーメニューを常時設置メニューからはホーム、最後の学習履歴のところまで飛べるボタン、説明ページの三種類
 - 仕様フレームワーク
    - react
 - 学習種類（仮）
    - サイト作成
      - html,css,js
      - 各種フレームワーク
      - python?
    - ゲーム制作
      - c#
      - unity
    - ロボットソフト
      - c
 - 初級学習イメージ
    - 最初に要素や動かすものをつくらせる
    - そこに命令や動きを持ったパズルを埋めていく
    - 最終的にイメージ通りのものを作る
 - 中級学習イメージ
    - 初級のように要素や動かすものを作るが用語を使ったタグにする
    - 命令や動きを与えるものも実際に使うものに変換
    - それぞれの命令や動きには説明がありどのような動きをしてくれるのかを教えてくれる
    - 試験は１０の要望を１００以上の中からランダム生成そのすべてをしっかりとこなし１０の要望のうち８個以上完璧に答えることで合格
 - 上級学習イメージ
    - これまでのはめ込み式とは違い実際にコードを打つ
    - コード打つにあたって必要な構築セットアップはしておく
    - 練習段階では横に辞書のようなものを置きいつでも調べられる状況を作る
    - 卒業試験はこれまで行ってきたことをスピードテスト方式で２０問をそれぞれに合わせた時間で８割正解することで合格卒業とする
    - なお卒業したのちおめでとう中途リアル終了だよとだしこれからは本番頑張ってねとバカでかい文字で出すようにする
 - アカウントと保持について
    - メールアドレスとパスワードを使用
    - ニックネームを作る
